
# Coffee House — Landing Page

Учебный проект в рамках курса **RS School (Fullstack Engineering)** — адаптивный двухстраничный сайт по макету Figma (Coffee House 2026Q3).

## Часть 2 — Функциональность (требования и критерии)

Цель: реализовать интерактивность страниц, созданных в Части 1, на чистом JavaScript без сторонних библиотек.

Коротко, что должно быть реализовано:
- Открытие/закрытие бургер-меню (адаптивно, до 768px).
- Слайдер/карусель на главной странице (не менее 3 элементов, цикличный, плавный).
- Переключение категорий в каталоге (Coffee / Tea / Dessert).
- Управление отображением карточек (кнопка "показать ещё" или пагинация).
- Модальное окно с информацией о выбранной карточке.
- Выбор параметров карточки в модалке и динамическое обновление связанной информации (цена, описание и т.д.).

### Данные каталога
- Каталог хранится в виде массива объектов в отдельном файле `.js` или `.json`.
- Каждый объект содержит все данные для карточки и модального окна: `id`, `name`, `description`, `image`, `basePrice`, `sizes`, `additives` и т.д.
- Карточки строятся динамически JavaScript-ом на основе этих данных. Данные не дублируются в HTML.

### Бургер-меню
- Работает на обеих страницах при ширине ≤ 768px.
- Кнопка переключает видимость меню и анимацию иконки (бургер ↔ крест). Открытие/закрытие — плавное.
- При открытом меню прокрутка страницы блокируется; по закрытии восстанавливается.
- При выборе ссылки меню закрывается и выполняется переход (на якорь или в каталог).
- Меню закрывается по `Escape`. При ширине ≥ 769px главное меню отображается, кнопка скрыта.

### Слайдер / карусель
- На главной странице реализован слайдер с не менее чем 3 элементами.
- Переключение кнопками «вперёд»/«назад», циклично, с плавной анимацией.
- Видимый элемент(ы) не выходят за границы контейнера; индикаторы (точки) отражают текущее состояние.

### Переключение категорий
- При загрузке каталога активна первая категория, отображаются её карточки.
- По клику другая категория становится единственной активной и отображается без перезагрузки страницы.

### Управление отображением карточек
- Используется механизм «показать ещё» или пагинация (в зависимости от макета/реализации).
- В шаблоне Coffee House: на ширине >768px отображаются все карточки; ≤768px — сначала 4 карточки и кнопка «показать ещё», если есть скрытые.
- Кнопка скрывается после показа всех карточек.

### Модальное окно
- Клик по карточке открывает модальное окно с затемнённым фоном, окно по центру экрана.
- Окно закрывается по кнопке, по оверлею или по `Escape`; клик внутри окна не закрывает.
- Пока окно открыто, прокрутка страницы блокируется.
- Окно корректно отображается на ширинах 1440px, 768px и 380px в обеих темах.

### Параметры карточки в модалке
- Модалка содержит не менее двух параметров (например: размер, добавки). Выбор визуально выделяется.
- При изменении параметров обновляются связанные данные (цена, краткое описание и т.д.) без перезагрузки.

```

├─ index.html                     # главная страница (hero, слайдер, секции)
├─ menu.html                      # страница каталога (категории, карточки)
├─ README.md                      # этот файл
├─ styles/                        # CSS по блокам
│  ├─ variables.css               # CSS-переменные, контейнер, отступы
│  ├─ base.css                    # normalize / базовые правила
│  ├─ common.css                  # header, footer, утилиты, общие компоненты
│  ├─ home.css                    # стили главной страницы (слайдер и т.д.)
│  └─ menu.css                    # стили каталога и модалки
├─ scripts/                       # логика приложения (vanilla JS)
│  ├─ theme.js                    # переключатель темы и сохранение в localStorage
│  ├─ burger-menu.js              # мобильная навигация (бургер)
│  ├─ slider.js                   # слайдер/карусель на главной
│  ├─ menu.js                     # переключение категорий и работа каталога
│  ├─ modal.js                    # модальное окно с выбором параметров
│  └─ ui.js                       # общие UI-хелперы (scroll-to-top и т.п.)
├─ assets/
│  ├─ icons/                      # логотипы, фавиконы, иконки
│  └─ images/                     # изображения
│     ├─ about/                   # галерея about
│     └─ menu/cards/              # картинки карточек каталога

```
